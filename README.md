# «Ветеринар на связи» — концепт редизайна vetnasvyaz.ru

Редизайн сайта ветеринарной клиники в Раменском. Весь контент — тексты, 27 направлений с ценами (778 позиций),
19 статей, отзывы, вакансии, контакты и фото клиники — взят с действующего vetnasvyaz.ru (19.10.2026).
Основа — проект `lubertsy-vet-next`: анимации и заглавная собака сохранены.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5199
npm run build      # статическая сборка в dist/
```

`?nointro` в адресе пропускает интро. `index.html` нельзя открыть двойным кликом — нужен сервер (`npm run dev` или `npm run preview`).
Сборка под подпапку GitHub Pages: `BASE=/vetnasvyaz-next/ npm run build` (делает workflow `.github/workflows/pages.yml`).

## Что изменилось относительно lubertsy-vet-next

- **Шрифт заголовков** — Piazzolla (вариативная антиква с кириллицей, оси толщины и оптического размера, курсив) вместо Unbounded. Анимация толщины букв под курсором работает на новом шрифте.
- **Заглавная собака на телефоне** — размер считается от реальной высоты и ширины экрана (`--stageH`, `--dogH` в `src/styles/vns.css`): собака целиком помещается по ширине, не наезжает на кнопки, а «НА СВЯЗИ.» и «прицел» привязаны к её голове. Проверено на 390×844 и 375×667.
- **Контент и страницы** — адреса совпадают с действующим сайтом: `/kardiologiya.html`, `/uslugi-i-tseny.html`, `/novosti/<статья>/`, `/o-kompanii.html`, `/vakansii.html`, `/contacts.html`. Все страницы пререндерятся в HTML, есть `sitemap.xml`.
- **Новые блоки** — фильтр направлений, поиск по всему прайсу с ранжированием, горизонтальная фотогалерея, отзывы, статьи, схема «Как нас найти» с маршрутом в Яндекс Картах.
- **Логотип** — папка `brand/` (генератор `tools/make-logo.py`, текст в кривых): знак «крест + волны связи», горизонтальная и вертикальная версии, тёмные варианты, иконка. Превью: `/brand/index.html`.

## Контент: что поправлено при переносе

- На странице «Лечение собак» в источнике написано «в Подольске» — заменено на «в Раменском»; исправлены явные опечатки («Ллечение», «рекоммендациям»).
- В каталоге источника карточка «Наркоз и анестезия» ведёт на страницу инфузионной терапии — здесь направление названо по странице: «Инфузионная терапия».
- На страницах «Инфузионная терапия» и «Орнитология» в источнике сбит текст — перенесены только связные абзацы.
- Эмодзи из статей убраны.

## Известные ограничения

- Фото клиники с сайта небольшого разрешения (до 1086 px); маленькие фото статей показаны компактно. Для продакшна лучше переснять.
- Часть атмосферных фото (собака-герой, кошка в финале, собака в editorial, кадры «Звонок» и «Подготовка») — Unsplash.
- Формы записи нет: запись по телефону, помощник готовит текст обращения для копирования.
- Ссылка на политику конфиденциальности ведёт на действующий сайт.
